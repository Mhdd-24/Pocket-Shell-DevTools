# Module tree

One PowerShell function (or small helper) per file. Load order is defined in `../pocket-shell-devtools.ps1`.

| Folder | Section |
|--------|---------|
| `shortcuts/` | Terminal shortcuts |
| `commit/` | Commit messages |
| `git/` | Git shortcuts |
| `nav/` | System navigation |
| `npm/` | npm scripts |
| `node/` | Node version |
| `angular/` | Angular CLI |
| `util/` | Ports, search, editors |
| `help/` | Help, banner, prompt |
| `config/` | Paths and repo map |
